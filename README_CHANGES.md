# Mehediadmin — আপডেটেড ফাইল

এই zip-এর ফোল্ডার-স্ট্রাকচার তোমার রিপোর ঠিক একই পাথ অনুসরণ করে — শুধু এক্সট্র্যাক্ট করে
প্রতিটা ফাইল তোমার রিপোর একই পাথে replace করে দাও, তারপর `npm run build` চালিয়ে দেখো।

## কী বদলেছে (lib/guide-content-parser.ts)

- হিরো/ভূমিকার দ্বিতীয় প্যারাগ্রাফ আগে "ভূমিকা" নামে একটা আলাদা দৃশ্যমান হেডিং নিয়ে
  বসত — এখন hero-এর ধারাবাহিক অংশ হিসেবে বসে, আলাদা লেবেল ছাড়া।
- "সংশ্লিষ্ট গাইড" সেকশন আগে শুধু "আরও পড়ুন" হেডিং চিনত ("সংশ্লিষ্ট গাইড..." চিনত না),
  আর লিংকের URL কখনোই সংরক্ষণ হতো না (সবসময় খালি থাকত) — দুটোই ঠিক।
- একের পর এক বোল্ড-লাইন (ব্ল্যাঙ্ক লাইন ছাড়া) লিখলে পুরো সেকশন একটা জগাখিচুড়ি
  প্যারাগ্রাফ হয়ে যেত — এখন কমপ্যাক্ট এক-লাইন কার্ড ফরম্যাটও (`**Title** — description`)
  সাপোর্টেড।
- `##` (২-হ্যাশ) হেডিংও এখন `###`-এর মতোই একটা নতুন সেকশন শুরু করে (আগে এটা silently
  আগের সেকশনের বডিতে মিশে যেত)।
- বুলেট-লিস্টের পরে একটা ব্যাখ্যা-বাক্য (বুলেট ফরম্যাটে না লেখা) থাকলে সেটা আগে চুপচাপ
  হারিয়ে যেত — এখন তালিকার শেষে যোগ হয়, হারায় না।
- বুলেট-ডিটেকশন এখন `-`/`–`/`—`/`•` সব প্রিফিক্সই চেনে (আগে শুধু `-`/`•`)।
- **নতুন:** প্রতিটা সেকশন-হেডিং, কার্ড-টাইটেল ও related-link টাইটেলের জন্য
  `inferIconKey()` ফাংশন স্বয়ংক্রিয়ভাবে একটা উপযুক্ত আইকন-key বসায় (`headingIcon`/
  `icon` ফিল্ডে) — Vangcur-এর `GuideIcons.tsx`-এ এই key-গুলো রেজিস্টার করা আছে।

## কী বদলেছে (types/guides.ts)

- `BaseBlock`-এ নতুন ঐচ্ছিক `headingIcon?: string` ফিল্ড যোগ হয়েছে — Vangcur-এর
  `types/guides.ts`-এর সাথে সিঙ্কে রাখতে এখানেও যোগ করা হলো।
